# Plan 3: VideosPage Extensions — Row Navigation + Delete

**Phase:** 7 — Video Detail Page + Delete UI
**Wave:** 3
**Requirements:** VDP-01, VDP-06, DEL-01, DEL-04
**Checkpoint:** human

## Goal

Extend the existing `VideosPage` with two features: (1) clicking any row (or a dedicated nav icon in
the Action column) navigates to `/videos/:id`, and (2) a per-row Delete button opens a confirmation
dialog and removes the video. All existing row buttons (`Re-ingest`, new nav icon, new delete button)
must call `e.stopPropagation()` so they do not trigger the row-level navigation click. Cache
invalidation after delete is handled automatically by `useDeleteVideo` (implemented in Plan 01) and
makes the video disappear from the grid immediately (DEL-04).

This plan depends on Plans 01 and 02 — the `useDeleteVideo` hook and the `/videos/:id` route must
exist before this plan is executed.

## Context

**Row click navigation (critical pattern):**
The `<tr>` element gets an `onClick` that navigates. Every interactive element inside the row
(`<button>`, `<a>`) must call `e.stopPropagation()` first, otherwise clicking any button will
trigger both the button action AND the navigation — causing an immediate page change.

```tsx
// On the <tr>:
onClick={() => navigate(`/videos/${video.id}`)}
className="... cursor-pointer hover:bg-gray-50"

// On EVERY button inside the row — without exception:
onClick={(e) => { e.stopPropagation(); /* then perform button action */ }}
```

**Delete confirmation pattern (match VideoModal.tsx):**
```tsx
import { Dialog, DialogPanel, DialogTitle } from '@headlessui/react';
// State: const [deleteTarget, setDeleteTarget] = useState<string | null>(null);
// Open:  setDeleteTarget(video.id)
// Close: setDeleteTarget(null)
// Confirm: await deleteMutation.mutateAsync(deleteTarget)
```

Use a single dialog instance for all rows (track `deleteTarget: string | null` — the ID of the video
pending deletion). Do NOT render one Dialog per row.

**Toast pattern:**
```typescript
import { addToast } from '../hooks/useToast';
addToast('Video deleted', 'success');
addToast(errorMessage, 'error');
```

**Hooks to add:**
- `useDeleteVideo` from `../api/videos` — already exists after Plan 01
- `useNavigate` from `react-router-dom` — already imported in the file as `Link`; add `useNavigate`

**Existing imports in VideosPage.tsx:**
```typescript

```
Must become:
```typescript

```

**Action column — final layout:**
The Action column currently has one button (`Re-ingest`). After this plan it will have three items:
1. Re-ingest button (existing — add `e.stopPropagation()`)

Keep them in a `<div className="flex items-center gap-2">` wrapper for alignment.

      addToast(err instanceof Error ? err.message : 'Delete failed', 'error');
